## Name

The project was called AgentGuard. Four arXiv papers already use that name (2502.09809, 2509.23864, 2605.28071, 2609.16287), so it is now OriginGuard. Still to check before publishing: PyPI, npm, GitHub and domain availability. A similar-sounding project, Origin Fortress, exists.
